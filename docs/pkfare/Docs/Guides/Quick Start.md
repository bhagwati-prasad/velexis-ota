# Quick Start

This guide will walk you through from nothing to your first booking from PKFARE.

Before you get started, you need to:
- sign up a PKFARE portal buyer account and Developer account
- get your Partner ID and KEY from our business manager
- use our API testing platform to create your first booking from PKFARE
