Velexis OTA SDK

The design for a multi-tenant OTA built as a NestJS + Next.js monolith. It covers a schema-per-tenant PostgreSQL design, the REST API that the NestJS backend implements on top of Amadeus Enterprise, and @velexis/ota-sdk, the JS SDK every OTA uses to build its Next.js storefront and its Amadeus-like console.
