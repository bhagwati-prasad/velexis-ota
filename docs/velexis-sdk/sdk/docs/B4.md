# B4 — Console (staff): developer guide

The `console` namespace of `@velexis/ota-sdk` powers the OTA's **staff console** — a small, Amadeus-like back office
built with Next.js (App Router) on top of the same SDK as the storefront. It covers:

| Namespace | What it does |
|---|---|
| `console.auth` | Staff sign-in with portal credentials (+ TOTP) or a portal token exchange, refresh, sign-out, `me` |
| `console.bookings` | **All** bookings of the OTA, full detail (net, markup, sync state, audit), PNR lookup + import, verbatim order retrieve, create on behalf of a customer, PATCH, issue, cancel, resync, notes |
| `console.queues` | Amadeus office queues (Queue List) and stored queue snapshots |
| `console.customers` | Customer accounts with statistics and bookings |
| `console.supplierRequests` | Redacted Amadeus call log (troubleshooting) |
| `console.amadeus` | Raw pass-through, one method per Amadeus operation, verbatim request/response |

Normal searching in the console reuses the shopping namespace (`flights.search`, `flights.availability`,
`flights.upsell`, `flights.price`) with the staff token — the console adds net prices and raw supplier data on top.

---

## 1. Keys, tokens and where code runs

* **Secret key only.** Every console call needs `sk_test_…` / `sk_live_…`, so console code runs **server-side
  only**: server components, server actions, route handlers, middleware. A publishable key gets
  `PermissionError` `SCOPE_NOT_ALLOWED`. Client components never hold a console client — they call server actions.
* **Staff token.** `console.auth.signIn` returns a `ConsoleStaffSession` (`session` = the tokens, `subject.type =
  "staff"`; plus `staff`, `tenant`, `permissions`). Keep `accessToken` (15 min) and the rotating `refreshToken` in
  **httpOnly, secure, SameSite=strict** cookies. Clients that hold staff tokens are created with
  `sessionKind: "staff"` (`createServerClient({ as: "staff" })` does it) — refresh tokens are opaque, so this option
  makes the SDK's automatic refresh call `console.auth.refresh` instead of the customer `auth.refresh`;
  `onSessionRefreshed` then receives `result.session` and `onStaffSessionRefreshed` the whole `ConsoleStaffSession`
  (updated permissions).
* **Key scopes** (`ConsoleApiKeyScope`, stored in `platform.api_keys.scopes`, set when the key is created in the
  Velexis portal) decide what a secret key may do on `/v1/console/**`:

| Scope | Console calls with a staff token | Console calls **without** a staff token | Use it for |
|---|---|---|---|
| `storefront` | refused (`SCOPE_NOT_ALLOWED`) | refused | the storefront deployment's `sk_…` — an SSRF or an unguarded server action there can never reach the back office |
| `console` (or no scope) | allowed, the staff role decides | refused (`SCOPE_NOT_ALLOWED`, `details.requiredScope = "console:automation"`) | the console deployment |
| `console:automation` | allowed | allowed with **exactly** the `StaffPermission`s also listed in the key's scopes (e.g. `["console:automation", "bookings:read", "queues:read"]`; `bookings:issue`, `bookings:cancel`, `amadeus:write` only when listed) — attributed to the API key in `staff_actions` | one key per cron job / back-office integration, minimum permissions |

* **Never fall back to the key alone.** A console client built from cookies must refuse to call when the staff cookie
  is missing — otherwise a signed-out visitor replaying a server action would call with the bare secret key. The
  helper below throws `AuthenticationError` `UNAUTHENTICATED` locally, and every console server action starts with
  `await requireStaff({ permissions: [...] })` (server actions are public POST endpoints).
* **Environment.** Test keys use the OTA's Amadeus *test* connection and see test bookings only; live keys the
  production connection. `me().tenant.environment` tells the UI which one it is (show a banner in test).
* **Roles → permissions** (`me().permissions`):

| Role | Permissions |
|---|---|
| owner, admin | everything incl. `amadeus:write` (raw create / issue / patch / cancel) |
| agent | `bookings:read/write/issue/cancel`, `customers:read`, `queues:read`, `supplier_requests:read`, `amadeus:read` |
| finance | `bookings:read`, `customers:read`, `supplier_requests:read` |
| viewer | `bookings:read`, `customers:read` |

* **Caching.** Everything is personal, priced or live supplier data: the SDK always sends `cache: "no-store"`.
  After a mutation call `revalidatePath()` for the pages you rendered.
* **Idempotency.** POSTs that change state get an `Idempotency-Key` automatically. Pass your own
  (`{ idempotencyKey }`) to tie retries of one user action together — e.g. one key per click on *Issue*, created in
  the client and sent with the form. A retry with the same key returns the stored result and never issues or books
  twice.
* **Optimistic locking.** `patch`, `issue` and `cancel` require `ifMatch` = the booking `version` you displayed.
  Stale → `PRECONDITION_FAILED` (412): reload and let the agent retry.

### Server helper

```ts
// lib/console.ts
import "server-only";
import { createServerClient, requireStaff } from "@velexis/ota-sdk/next";

/**
 * Staff-only clients (console deployment key, scope `console`): staff cookies, `sessionKind: "staff"`, rotated
 * tokens written back. Without a staff cookie they throw AuthenticationError UNAUTHENTICATED locally — a console
 * call never goes out with the secret key alone.
 */
export const staffClient = () => createServerClient({ as: "staff" });            // flights.* + console.*
export async function consoleServer() { return (await staffClient()).console; }

/** Signed-in staff member (console.auth.me, deduplicated per request); redirects to sign-in, FORBIDDEN without the permissions. */
export { requireStaff };
```

Without the Next.js helpers, the guard is explicit:

```ts
import { cookies } from "next/headers";
import { AuthenticationError, createVelexisClient } from "@velexis/ota-sdk";

export async function consoleServerManual() {
  const jar = await cookies();
  const accessToken = jar.get("vx_staff_at")?.value;
  const refreshToken = jar.get("vx_staff_rt")?.value;
  if (!accessToken && !refreshToken) throw new AuthenticationError({ code: "UNAUTHENTICATED", message: "Staff session required", status: 401 });
  return createVelexisClient({
    secretKey: process.env.VELEXIS_CONSOLE_SECRET_KEY!, // sk_… scoped `console`
    accessToken, refreshToken,
    sessionKind: "staff",                               // refresh with console.auth.refresh
    // rotated tokens are written back by the middleware (cookies are read-only in server components)
  }).console;
}
```

### Session refresh in middleware

```ts
// middleware.ts
import { NextResponse, type NextRequest } from "next/server";
import { createVelexisClient } from "@velexis/ota-sdk";

export async function middleware(req: NextRequest) {
  if (!req.nextUrl.pathname.startsWith("/console") || req.nextUrl.pathname === "/console/sign-in") return NextResponse.next();
  const at = req.cookies.get("vx_staff_at")?.value;
  const rt = req.cookies.get("vx_staff_rt")?.value;
  if (at) return NextResponse.next();                       // cookie expiry == token expiry
  if (!rt) return NextResponse.redirect(new URL("/console/sign-in", req.url));
  try {
    const s = await createVelexisClient({ secretKey: process.env.VELEXIS_SECRET_KEY! }).console.auth.refresh({ refreshToken: rt });
    const res = NextResponse.next();
    res.cookies.set("vx_staff_at", s.session.accessToken, { httpOnly: true, secure: true, sameSite: "strict", expires: new Date(s.session.accessTokenExpiresAt) });
    res.cookies.set("vx_staff_rt", s.session.refreshToken, { httpOnly: true, secure: true, sameSite: "strict", path: "/console", expires: new Date(s.session.refreshTokenExpiresAt) });
    return res;
  } catch {
    const res = NextResponse.redirect(new URL("/console/sign-in", req.url));
    res.cookies.delete("vx_staff_rt");
    return res;
  }
}
export const config = { matcher: ["/console/:path*"] };
```

(`@velexis/ota-sdk/next` ships an equivalent `velexisMiddleware({ console: true })`; the code above shows what it does.)

## 2. Flow — staff sign-in

1. **Sign-in form** (client component) posts to a server action with `useActionState`.
2. **Server action** calls `console.auth.signIn` with the secret key. `STAFF_MFA_REQUIRED` means "show the TOTP
   field and submit again"; the portal can also deep-link with a one-time token (`grantType: "portal_token"`).
3. Tokens go into httpOnly cookies; redirect to the console.

```ts
// app/console/sign-in/actions.ts
"use server";
import { cookies } from "next/headers";
import { redirect } from "next/navigation";
import { createVelexisClient, isVelexisError } from "@velexis/ota-sdk";

export type SignInState = { needMfa?: boolean; error?: string };

export async function signInAction(_: SignInState, form: FormData): Promise<SignInState> {
  const vx = createVelexisClient({ secretKey: process.env.VELEXIS_SECRET_KEY! });
  try {
    const s = await vx.console.auth.signIn({
      grantType: "password",
      email: String(form.get("email")),
      password: String(form.get("password")),
      mfaCode: form.get("mfaCode") ? String(form.get("mfaCode")) : undefined,
    });
    const jar = await cookies();
    jar.set("vx_staff_at", s.session.accessToken, { httpOnly: true, secure: true, sameSite: "strict", expires: new Date(s.session.accessTokenExpiresAt) });
    jar.set("vx_staff_rt", s.session.refreshToken, { httpOnly: true, secure: true, sameSite: "strict", path: "/console", expires: new Date(s.session.refreshTokenExpiresAt) });
  } catch (e) {
    if (isVelexisError(e, "STAFF_MFA_REQUIRED")) return { needMfa: true };
    if (isVelexisError(e, "INVALID_CREDENTIALS")) return { error: "Wrong e-mail or password." };
    if (isVelexisError(e, "ACCOUNT_LOCKED")) return { error: "Too many attempts — try again in 15 minutes." };
    if (isVelexisError(e, "STAFF_MEMBERSHIP_INACTIVE")) return { error: "You are not a staff member of this OTA." };
    throw e;
  }
  redirect("/console/bookings");
}

// Portal deep link: /console/sso?token=ptk_… → route handler
export async function exchangePortalToken(portalToken: string) {
  const s = await createVelexisClient({ secretKey: process.env.VELEXIS_SECRET_KEY! }).console.auth.signIn({ grantType: "portal_token", portalToken });
  return s; // set the same cookies as above, then redirect
}
```

## 3. Flow — the bookings work list

`console.bookings.list` returns every booking of the OTA (storefront, console and imported, customers and guests,
all statuses incl. `failed`). Filters are AND-ed, list values OR-ed. Typical saved views:

| View | Params |
|---|---|
| To issue in the next 24 h | `{ status: ["confirmed","partially_ticketed"], ticketingDeadlineBefore: in24h, sort: "ticketingDeadline" }` |
| Ticketing problems | `{ ticketingStatus: ["failed","manual_review"] }` |
| Find by passenger | `{ travelerLastName: "BERG", departureFrom: "2026-11-01" }` |
| A customer's bookings | `{ customerId }` or guests `{ customerEmail }` |
| Paid but not ticketed | `{ paymentStatus: ["paid"], status: ["confirmed"] }` |
| Failed create-orders | `{ status: ["failed"] }` |

```tsx
// app/console/bookings/page.tsx
import { consoleServer } from "@/lib/console";

export default async function BookingsPage({ searchParams }: { searchParams: Promise<Record<string, string | undefined>> }) {
  const sp = await searchParams;
  const page = await (await consoleServer()).bookings.list({
    q: sp.q,
    status: sp.status ? (sp.status.split(",") as ("confirmed" | "partially_ticketed")[]) : undefined,
    ticketingDeadlineBefore: sp.due === "24h" ? new Date(Date.now() + 864e5).toISOString() : undefined,
    sort: sp.due ? "ticketingDeadline" : "-created",
    cursor: sp.cursor,
    limit: 50,
  });
  return (
    <>
      <p>{page.totalCount ?? "10 000+"} bookings</p>
      <table>
        <tbody>
          {page.data.map((b) => (
            <tr key={b.id}>
              <td><a href={`/console/bookings/${b.id}`}>{b.reference}</a> / {b.recordLocator ?? "—"}</td>
              <td>{b.leadTravelerName} ×{b.travelersCount}</td>
              <td>{b.originCode}→{b.destinationCode} {b.departureAt.slice(0, 10)}</td>
              <td>{b.status} · {b.ticketingStatus} · due {b.ticketingDeadlineAt ?? "—"}</td>
              <td>{b.total.amount} (net {b.net.amount}, markup {b.markup.amount}) {b.total.currency}</td>
              <td>{b.paymentStatus} · sync {b.syncStatus}</td>
            </tr>
          ))}
        </tbody>
      </table>
      {page.page.nextCursor && <a href={`?cursor=${page.page.nextCursor}`}>Next</a>}
    </>
  );
}
```

To export everything (server-side job with a `console:automation` key that lists `bookings:read`):
`for await (const b of await vx.bookings.list({ createdFrom })) { … }`.

`syncStatus` (list) and `supplierSync.status` (detail) use one vocabulary, `ConsoleBookingSyncStatus`: `refreshed`
(synchronised by this request), `fresh` (< 6 h), `stale`, `throttled` (refresh skipped, synced moments ago), `failed`,
`order_not_found` (Amadeus no longer knows the order), `not_applicable` (no Amadeus order: pending / failed). List rows
never show `refreshed` / `throttled`. The customer-shaped `syncStatus` that `ConsoleBooking` inherits from `Booking`
carries the same value except `order_not_found` → `failed` and `not_applicable` → `fresh` — read `supplierSync.status`
in console UIs.

### Server actions

```ts
// app/console/bookings/[bookingId]/actions.ts
"use server";
import { revalidatePath } from "next/cache";
import { isVelexisError, type VelexisError } from "@velexis/ota-sdk";
import { consoleServer, requireStaff } from "@/lib/console";

type Result = { ok?: true; error?: string; reload?: true };
// Every action re-checks the staff session and permission first: server actions are public POST endpoints.

function explain(e: unknown): Result {
  if (isVelexisError(e, "PRECONDITION_FAILED") || isVelexisError(e, "VERSION_CONFLICT")) return { error: "The booking changed meanwhile — reloaded.", reload: true };
  if (isVelexisError(e, "SUPPLIER_REJECTED") || isVelexisError(e, "TICKETING_FAILED")) {
    const s = (e as VelexisError).supplier;
    return { error: `Amadeus ${s?.code ?? ""} ${s?.title ?? ""} ${s?.detail ?? ""}`.trim() };
  }
  if (isVelexisError(e, "SUPPLIER_TIMEOUT")) return { error: "Amadeus did not answer — press Sync before retrying." };
  if (isVelexisError(e, "FORBIDDEN")) return { error: "Your role does not allow this." };
  throw e;
}

export async function issueAction(bookingId: string, version: number, clickId: string): Promise<Result> {
  await requireStaff({ permissions: ["bookings:issue"] });
  try {
    await (await consoleServer()).bookings.issue({ bookingId, ifMatch: version, reason: "Issued from console" }, { idempotencyKey: clickId, timeoutMs: 90_000 });
  } catch (e) {
    if (isVelexisError(e, "PAYMENT_REQUIRED")) return { error: "The customer's payment is not captured yet." };
    if (isVelexisError(e, "ALREADY_ISSUED")) return { ok: true };
    return explain(e);
  } finally {
    revalidatePath(`/console/bookings/${bookingId}`);
  }
  return { ok: true };
}

export async function cancelAction(bookingId: string, version: number, form: FormData): Promise<Result> {
  await requireStaff({ permissions: ["bookings:cancel"] });
  try {
    await (await consoleServer()).bookings.cancel({
      bookingId, ifMatch: version,
      // refunds.reason: no_payment / ticketing_deadline / airline_request → booking_cancelled, other codes unchanged
      reasonCode: "customer_request", reason: String(form.get("reason")),
      refund: form.get("refund") === "full" ? { mode: "full" } : { mode: "none" },
      notifyCustomer: form.get("notify") === "on",
    });
  } catch (e) { return explain(e); }
  revalidatePath(`/console/bookings/${bookingId}`);
  return { ok: true };
}

export async function patchApisAction(bookingId: string, version: number, travelerId: string, passport: { number: string; expiryDate: string; issuanceCountry: string; nationality: string }): Promise<Result> {
  await requireStaff({ permissions: ["bookings:write"] });
  try {
    await (await consoleServer()).bookings.patch({
      bookingId, ifMatch: version,
      travelers: [{ id: travelerId, documents: [{ documentType: "PASSPORT", holder: true, ...passport }] }], // merged over the stored traveller
      remarks: { general: [{ subType: "QUALITY_CONTROL", text: "APIS COMPLETED BY DESK" }] }, // added to the existing remarks (mergeRemarks)
      reason: "Passport received",
    });
  } catch (e) { return explain(e); }
  revalidatePath(`/console/bookings/${bookingId}`);
  return { ok: true };
}

export async function tagAction(bookingId: string, version: number, form: FormData): Promise<Result> {
  await requireStaff({ permissions: ["bookings:write"] });
  const tags = String(form.get("tags") ?? "").split(",").map((s) => s.trim()).filter(Boolean);
  try { await (await consoleServer()).bookings.patch({ bookingId, ifMatch: version, tags, reason: "Re-tag" }); } // local only, no Amadeus call
  catch (e) { return explain(e); }
  revalidatePath(`/console/bookings/${bookingId}`);
  return { ok: true };
}

export async function syncAction(bookingId: string) {
  await requireStaff({ permissions: ["bookings:write"] });
  const r = await (await consoleServer()).bookings.resync({ bookingId, include: ["bags"] });
  revalidatePath(`/console/bookings/${bookingId}`);
  return r.changes.map((c) => c.label);
}

export async function addNoteAction(bookingId: string, form: FormData) {
  await requireStaff(); // the API checks bookings:write (finance may also add notes)
  await (await consoleServer()).bookings.addNote({ bookingId, text: String(form.get("text")), visibleToCustomer: form.get("public") === "on" });
  revalidatePath(`/console/bookings/${bookingId}`);
}
```

### Other PATCH elements

`console.bookings.patch` sends the Flight Order Management PATCH elements inside `data`. Amadeus PATCH **replaces**
every top-level element it receives and keeps the others, so Velexis merges three elements with the stored order
first; everything else replaces the order's element — send the complete list:

| Element | Semantics | Example |
|---|---|---|
| `travelers` | merged by `id` over the stored traveller (`mergeTravelers`, default true) | `[{ id: "1", documents: [...] }]` |
| `contacts` | replaces the stored contact with the same `purpose`, others kept (`mergeContacts`, default true; `false` replaces the list) | `[{ purpose: "STANDARD", emailAddress, phones: [{ deviceType: "MOBILE", countryCallingCode: "33", number }] }]` |
| `remarks` | **added** to the stored remarks, duplicates skipped (`mergeRemarks`, default true); `false` = each `general` / `airline` list replaces that kind (send the remaining remarks to delete one) | `{ general: [{ subType: "CONFIDENTIAL", text }], airline: [{ subType: "OTHER_SERVICE_INFORMATION", airlineCode: "AF", text }] }` |
| `formOfPayments` | replaces | `[{ other: { method: "ACCOUNT", flightOfferIds: ["1"] } }]`, `creditCard`, `b2bWallet` |
| `ticketingAgreement` | replaces; `delay` is the only settable time limit — `dateTime` / `segmentIds` are read-only Amadeus outputs (`VALIDATION_FAILED`) | `{ option: "DELAY_TO_CANCEL", delay: "3D" }` or `{ option: "CONFIRM" }` |
| `automatedProcess` | replaces the list | `[{ code: "DELAYED", queue: { number: "50", category: "2" }, officeId, delay: "1D", text }]` |
| `queuingOfficeId` / `ownerOfficeId` | replaces | `"PAR1A2100"` (must be an office of the OTA's connection) |
| `associatedRecords`, `tickets` | replace | verbatim Amadeus elements |
| `commissions` | replaces | `[{ controls: ["MANUAL"], values: [{ commissionType: "NEW", percentage: 1.5 }] }]` |
| `formOfIdentifications` | replaces | `[{ identificationType: "PASSPORT", carrierCode: "AF", number, travelerIds: ["1"] }]` |
| `flightOffers` (partial `ConsoleAmadeusFlightOffer`) | adds services | `travelerPricings[].fareDetailsBySegment[].additionalServices`: `chargeableSeat`, `chargeableCheckedBags`, `chargeableCabinBags: { quantity: 1 }`, `otherServices` |
| `tags`, `metadata` | **local only** (replace `bookings.tags` / `metadata`; no Amadeus call, any status) | `{ tags: ["corporate", "vip"] }` |

## 5. Flow — PNR lookup and import

1. The agent types a record locator → `console.bookings.findByRecordLocator` (Get Flight Order By Record Locator).
2. Each match says whether it is already a booking (`bookingId`) or `importable`.
3. *Import* → `console.bookings.import` attaches it to the OTA's tables (channel `import`), optionally for a customer
   and with a selling price.

```tsx
// app/console/pnr/page.tsx
import { isVelexisError } from "@velexis/ota-sdk";
import { consoleServer } from "@/lib/console";
import { importAction } from "./actions";

export default async function PnrPage({ searchParams }: { searchParams: Promise<{ rl?: string }> }) {
  const { rl } = await searchParams;
  if (!rl) return <form><input name="rl" pattern="[A-Za-z0-9]{5,8}" /><button>Look up</button></form>;
  const r = await (await consoleServer()).bookings.findByRecordLocator({ reference: rl.toUpperCase(), include: ["bags"] })
    .catch((e) => (isVelexisError(e, "NOT_FOUND") ? null : Promise.reject(e)));
  if (!r) return <p>No PNR {rl}.</p>;
  return r.matches.map((m) => (
    <section key={m.flightOrderId}>
      <h2>{m.summary.recordLocators.map((x) => `${x.originSystemCode}:${x.reference}`).join(" / ")}</h2>
      <p>{m.summary.travelers.map((t) => `${t.firstName} ${t.lastName}`).join(", ")}</p>
      <p>{m.summary.segments.map((s) => `${s.carrierCode}${s.number} ${s.originCode}-${s.destinationCode} ${s.departureAt} ${s.bookingStatus}`).join(" | ")}</p>
      {m.bookingId ? <a href={`/console/bookings/${m.bookingId}`}>Open booking {m.bookingReference}</a>
        : <form action={importAction.bind(null, rl.toUpperCase(), m.flightOrderId)}><button>Import</button></form>}
    </section>
  ));
}
```

// app/console/pnr/actions.ts

import { redirect } from "next/navigation";

## 6. Flow — assisted booking for a customer

Searching uses the normal shopping API with the staff token; booking uses `console.bookings.create` with the full
Flight Create Orders body.

```ts
// app/console/new-booking/actions.ts
"use server";
import { isVelexisError, type ConsoleBookingTimeoutDetails, type Schemas } from "@velexis/ota-sdk";
import { redirect } from "next/navigation";
import { requireStaff, staffClient } from "@/lib/console"; // createServerClient({ as: "staff" }): never key-only

export async function searchAndPrice(form: FormData) {
  await requireStaff({ permissions: ["bookings:write"] });
  const vx = await staffClient();
  const search = await vx.flights.search({ mode: "simple", originLocationCode: String(form.get("from")), destinationLocationCode: String(form.get("to")), departureDate: String(form.get("date")), adults: 1 });
  const results = await vx.flights.listResults({ searchId: search.id, limit: 20 });
  // staff see net + markup on each offer; pick one and price it
  return vx.flights.price({ offerIds: [results.data[0]!.id], include: ["bags", "detailed-fare-rules"] });
}

export async function bookForCustomer(pricedOfferId: string, customerId: string, travelers: Schemas["AmadeusTraveler"][], attemptKey: string) {
  await requireStaff({ permissions: ["bookings:write"] });
  const vx = await staffClient();
  let bookingId: string;
  try {
    const b = await vx.console.bookings.create({
      pricedOfferId, customerId, travelers,
      remarks: { general: [{ subType: "GENERAL_MISCELLANEOUS", text: "BOOKED BY PHONE" }] },
      ticketingAgreement: { option: "DELAY_TO_QUEUE", delay: "2D" }, // delay only: dateTime is a read-only Amadeus output
      automatedProcess: [{ code: "IMMEDIATE", queue: { number: "50", category: "0" }, text: "TO ISSUE" }],
      formOfPayments: [{ other: { method: "ACCOUNT", flightOfferIds: ["1"] } }],
      issue: false,
      pricing: { mode: "markup_rules" },
      reason: "Hotline booking",
    }, { idempotencyKey: attemptKey, timeoutMs: 90_000 });
    bookingId = b.id;
  } catch (e) {
    if (isVelexisError(e, "PRICE_CHANGED")) return { priceChanged: e.details };
    if (!isVelexisError(e, "SUPPLIER_TIMEOUT")) throw e;
    // The order may exist. The API kept a pending booking and returns it: open it, never re-book with a new key.
    bookingId = (e.details as ConsoleBookingTimeoutDetails).bookingId;
  }
  redirect(`/console/bookings/${bookingId}`);
}
```

**After `SUPPLIER_TIMEOUT`.** `error.details` (`ConsoleBookingTimeoutDetails`) names the `pending` booking that was kept
(`bookingId`, `reference`, `reconcileBy`). Its page shows `status = pending` and `supplierSync.status = not_applicable`;
poll `console.bookings.get` (or `router.refresh()` every few seconds) until the reconciliation job (≤ 15 min) has found
the order (status `confirmed`, `amadeusOrderId` set — `resync` works from then on) or marked the booking `failed`.
Repeating `create` with the **same** idempotency key is safe (the SDK's automatic retries do exactly that): it never
calls Flight Create Orders again, replays the 504 (`details.replayed: true`) while reconciliation is undecided and then
returns the final booking or error. Never retry with a new key. (The raw `console.amadeus.createFlightOrders` keeps no
booking row after a timeout: look at the queue or the PNR before booking again.)

Raw offers found with `console.amadeus.searchFlightOffers` can be booked the same way: price them with
`flights.price({ amadeusFlightOffers: [offer] })` (console scope) and pass the resulting `prc_…` to
`console.bookings.create`.

## 9. Flow — raw Amadeus console (advanced mode)

`console.amadeus.*` mirrors the Amadeus paths under `/v1/console/amadeus/…` and accepts/returns the **verbatim**
Amadeus structures, so nothing Amadeus allows is out of reach. Each result is `{ call, amadeus }` (plus `bookingId`
for orders): `call.supplierRequestId` links to the supplier log, `call.correlationId` is the Amadeus
`ama-request-id`. Prices are **net**. Read methods need `amadeus:read`; create/issue/patch/cancel need
`amadeus:write` (owner, admin).

```ts
// app/console/amadeus/actions.ts — a "terminal-like" flow: availability → search → price → book → issue
"use server";
import { consoleServer, requireStaff } from "@/lib/console";

export async function rawFlow() {
  await requireStaff({ permissions: ["amadeus:read", "amadeus:write"] }); // creates and issues an order
  const vx = await consoleServer();

  // 1. Seat availability per class (Flight Availabilities Search)
  const avail = await vx.amadeus.searchFlightAvailabilities({
    amadeus: { originDestinations: [{ id: "1", originLocationCode: "CDG", destinationLocationCode: "JFK", departureDateTime: { date: "2026-11-20", time: "10:00:00" } }], travelers: [{ id: "1", travelerType: "ADULT" }], sources: ["GDS"] },
  });

  // 2. Offers (Flight Offers Search POST — every searchCriteria field available)
  const offers = await vx.amadeus.searchFlightOffers({
    amadeus: {
      currencyCode: "EUR",
      originDestinations: [{ id: "1", originLocationCode: "CDG", destinationLocationCode: "JFK", departureDateTimeRange: { date: "2026-11-20", time: "10:00:00", timeWindow: "2H" } }],
      travelers: [{ id: "1", travelerType: "ADULT", fareOptions: ["STANDARD"] }],
      sources: ["GDS"],
      searchCriteria: { maxFlightOffers: 10, additionalInformation: { brandedFares: true }, flightFilters: { carrierRestrictions: { includedCarrierCodes: ["AF"] } } },
    },
  });
  const offer = offers.amadeus.data[0]!;

  // 3. Branded fares of that offer (Branded Fares Upsell)
  const upsell = await vx.amadeus.upsellAirOffers({ amadeus: { data: { type: "flight-offer-upsell", flightOffers: [offer] } } });

  // 4. Confirm the price + bags + fare rules + card fees (Flight Offers Price); offers are ConsoleAmadeusFlightOffer, so
  //    additionalServices may carry chargeableCabinBags / chargeableCheckedBags / chargeableSeat
  const priced = await vx.amadeus.quoteAirOffers({
    include: ["bags", "credit-card-fees", "detailed-fare-rules"], forceClass: false,
    amadeus: { data: { type: "flight-offer-pricing", flightOffers: [upsell.amadeus.data[0] ?? offer], payments: [{ brand: "VISA", binNumber: 424242, flightOfferIds: ["1"] }] } },
  });

  // 5. Book (Flight Create Orders) and attach it to the OTA's tables in the same call
  const order = await vx.amadeus.createFlightOrders({
    issue: false, importAsBooking: true, reason: "Raw booking",
    amadeus: { data: {
      type: "flight-order",
      flightOffers: priced.amadeus.data.flightOffers,
      travelers: [{ id: "1", dateOfBirth: "1985-07-21", gender: "MALE", name: { firstName: "JONAS", lastName: "WEBER" }, contact: { emailAddress: "jonas.weber@example.com", phones: [{ deviceType: "MOBILE", countryCallingCode: "49", number: "15123456789" }] } }],
      ticketingAgreement: { option: "DELAY_TO_CANCEL", delay: "6D" },
      remarks: { general: [{ subType: "GENERAL_MISCELLANEOUS", text: "RAW CONSOLE BOOKING" }] },
    } },
  }, { timeoutMs: 90_000 });

  // 6. Issue (Flight Order Issue) — or use console.bookings.issue({ bookingId: order.bookingId!, ifMatch }) for the managed flow
  const issued = await vx.amadeus.issueFlightOrder({ flightOrderId: order.flightOrderId, amadeus: { data: { formOfPayments: [{ other: { method: "CASH", flightOfferIds: ["1"] } }] } } });

  return { classes: avail.amadeus.data.length, tickets: issued.amadeus.data.tickets ?? [] };
}
```

## 10. Error handling

All errors are `VelexisError` subclasses (`import { isVelexisError } from "@velexis/ota-sdk"`). In console scope
`error.supplier` carries the Amadeus error (code, title, detail, source) when one exists.

| Code (HTTP) | Class | Typical cause in the console | What to do |
|---|---|---|---|
| `VALIDATION_FAILED`, `INVALID_REQUEST` (400) | `ValidationError` | malformed params / body (also read-only `ticketingAgreement.dateTime` / `segmentIds` sent, fieldErrors code `read_only`) | show `fieldErrors` |
| `UNAUTHENTICATED`, `TOKEN_EXPIRED` (401) | `AuthenticationError` | staff session missing/expired | refresh (middleware) or redirect to sign-in |
| `INVALID_CREDENTIALS`, `STAFF_MFA_REQUIRED`, `PORTAL_TOKEN_INVALID` (401) | `AuthenticationError` | sign-in | show message / TOTP field / reopen from portal |
| `REFRESH_TOKEN_INVALID`, `REFRESH_TOKEN_REUSED` (401) | `AuthenticationError` | refresh | sign out |
| `PAYMENT_REQUIRED`, `PAYMENT_DECLINED` (402) | `PaymentError` | issue before the customer's payment is captured | wait / `allowUnpaid` (owner, admin) |
| `FORBIDDEN` (403) | `PermissionError` | role lacks `details.requiredPermission` | hide the action (`me().permissions`) |
| `STAFF_MEMBERSHIP_INACTIVE`, `TENANT_SUSPENDED`, `FEATURE_DISABLED` (403) | `PermissionError` | removed member, suspended OTA, raw access disabled | sign out / fix configuration |
| `SCOPE_NOT_ALLOWED` (403) | `PermissionError` | publishable key, a key scoped `storefront`, or a key-only call from a key without `console:automation` (`details.requiredScope`) | use the console key + a staff token; give automation keys `console:automation` + the permissions they need |
| `OFFICE_NOT_ALLOWED` (403) | `PermissionError` | office id not on the OTA's Amadeus connection | pick one of `me().tenant.supplier.officeIds` |
| `NOT_FOUND` (404) | `NotFoundError` | unknown booking / customer / PNR / order | — |
| `VERSION_CONFLICT` (409) | `ConflictError` | Amadeus 2552 SIMULTANEOUS UPDATE or concurrent edit | resync, reload, retry |
| `ALREADY_ISSUED`, `BOOKING_ALREADY_CANCELLED`, `BOOKING_NOT_MODIFIABLE` (409) | `ConflictError` | state changed | reload |
| `ORDER_ALREADY_IMPORTED` (409) | `ConflictError` | import of an attached order | open `details.bookingId` |
| `PRICE_CHANGED` (409) | `PriceChangedError` | re-pricing at create | show `newPrice`, confirm with `details.pricedOfferId` |
| `SOLD_OUT` (409) | `SoldOutError` | fare gone | search again |
| `IDEMPOTENCY_KEY_REUSED` (409) | `ConflictError` | same key, different body | new key per new action |
| `OFFER_EXPIRED` (410) | `ExpiredError` | priced offer expired with `repriceIfExpired: false` | price again |
| `PRECONDITION_FAILED` (412) | `VelexisError` | stale `ifMatch` | reload the booking |
| `SUPPLIER_REJECTED`, `TRAVELER_DATA_INVALID`, `CONTACT_DATA_INVALID`, `UNPROCESSABLE` (422) | `ValidationError` | Amadeus 4xx (verbatim `details.errors`), data rules | fix data; show `error.supplier` |
| `ACCOUNT_LOCKED` (423) | `VelexisError` | 5 failed sign-ins | wait `Retry-After` |
| `RATE_LIMITED` (429) | `RateLimitError` | resync throttle (10 s), raw limit (30/min) | wait `retryAfterSeconds` |
| `SUPPLIER_NOT_CONFIGURED` (424) | `SupplierError` | no Amadeus connection for the environment | configure in the portal |
| `SUPPLIER_ERROR`, `TICKETING_FAILED` (502) | `SupplierError` | Amadeus 5xx / ticketing refusal (e.g. 9112) | check supplier log, retry later |
| `SUPPLIER_UNAVAILABLE`, `SERVICE_UNAVAILABLE` (503) | `SupplierError` / `ServerError` | outage | retry later |
| `SUPPLIER_TIMEOUT` (504) | `SupplierError` | Amadeus did not answer — outcome unknown | `create`: open `details.bookingId` (pending booking), never re-book with a new key; other writes: `resync` / PNR lookup, then retry with the **same** idempotency key |
| `INTERNAL_ERROR` (500) | `ServerError` | bug | quote `requestId` |
